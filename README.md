# 💗 Convite Digital Interativo

Um convite digital interativo desenvolvido como projeto pessoal de estudo e prática de desenvolvimento web.

A proposta é criar uma experiência divertida e personalizada, na qual a pessoa convidada pode aceitar ou recusar o convite, escolher uma data, um horário e sugerir o local do encontro.

## ✨ Funcionalidades

- Tela inicial interativa com opções de aceitar ou recusar o convite.
- Botão de recusa com comportamento dinâmico.
- Seleção de data e horário.
- Escolha do local do encontro.
- Campo para inserir uma sugestão personalizada.
- Tela de confirmação com o resumo das escolhas.
- Registro das respostas em banco de dados SQLite.
- Interface responsiva para diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura das páginas.
- **CSS3:** estilização e responsividade.
- **JavaScript:** interatividade e manipulação dos elementos da página.
- **Python:** lógica do backend.
- **Flask:** comunicação entre frontend e backend.
- **SQLite:** armazenamento das respostas.

## 🚀 Como executar localmente

1. Clone o repositório:

```bash
git clone https://github.com/RenataCMB/convite-digital.git
```

2. Entre na pasta do projeto:

```bash
cd convite-digital
```

3. Crie um ambiente virtual:

```bash
python -m venv .venv
```

4. Ative o ambiente virtual no Windows:

```bash
.venv\Scripts\activate
```

5. Instale o Flask:

```bash
pip install Flask
```

6. Execute a aplicação:

```bash
python app.py
```

7. Acesse no navegador:

```text
http://127.0.0.1:5000
```
